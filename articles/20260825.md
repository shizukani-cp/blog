こんにちは。よくA君やC君とチャットしている静カニです。
この間、C「健康食品くれ」A「そんなあなたにヤクルト1000」C「よりもB-29」「B-29は積載量9tという高カロリー」という会話がありました。
文脈ガバガバなのでCくんの発言の文脈に対する妥当性の検討は置いといて、t(トン)は質量の単位です。一方で、「高カロリー」のカロリーは熱量のことでしょう。
つまり単位が違うわけです。ということでB-29のカロリーをいくつかの面から検討していきます。

※この記事では小数点以下は適当に扱っています。整数にはしていますが四捨五入してたり切り捨てたりしてるかもしれません。基本1の位が変わってもそこまで影響はないので許してください。
## 積載量
何の積載量かよく分かりませんが9tを直接熱量に変換しておけばいいでしょう。100%変換させるとしてE=mc^2の単位は`E[J]`,`m[kg]`,`c[m/s]`なので
```
m = 9t = 9_000kg
c = 300_000km/s = 300_000_000m/s
E = 9_000kg * (300_000_000m/s)^2 = 9_000kg * (90_000_000_000_000_000m^2/s^2)
  = 810_000_000_000_000_000_000J = 193_594_646_271_510_500_000cal = 193_594_646_271_510_500kcal
```
よって積載量の9tを相対性理論に従って丸ごと熱量に変換すると19京kcal(SI接頭語だと193Pcal)になるらしいです。
### 適正な栄養は?
「30mm4門を持つ震電ちゃんの腹を満たす」ためだそうですがさすがに193Pcalは栄養過多な気がします。ということで震電ちゃんなるものの適正な栄養を考えます。
震電って調べたところ戦闘機なので、栄養=燃料と考えてよいでしょう。震電は胴体、翼内合わせて800L、増槽はないようです。
ガソリンの発熱量は`45MJ/kg`で、密度が`783g/L`だそうです。
```
45MJ/kg * 783g/L = 45_000J/g * 783g/L = 35_235_000J/L
35_235_000J/L *   800L = 28_188_000_000J =  6_737_094_000cal
```
6.7Gcalが適正というか満腹になる栄養(熱量)ですね。193Pcalは7.8万年分に相当しますね。栄養過多どころの騒ぎではありません。
## 積載量その2
さすがに9tをそのまま相対性理論に従って100%変換するのは無理がありますよね。9tが戦闘食と仮定してみます。
B-29は非ミリタリーオタクからすると二次大戦期に活躍したぐらいのイメージしかないので、適当に二次大戦期の戦闘食を調べて出てきたCレーションということにしておきます。
6缶で5ポンド10オンス、4437カロリーだったらしいです。4437カロリーはcalなのかkcalなのかと思いましたがキュウリのカロリーが13kcalなのでさすがに4437kcalでしょう。
```
5lb + 10oz = 90oz = 2_551g
9t / 2_551g = 9_000_000g / 2_551g = 3_528
4437kcal * 3_528 = 15_653_736_000cal = 15_653_736kcal
```
よって積載量の9tが全てCレーションと仮定すると1565万kcal(SI以下略15.6Gcal)らしいです。二食分+αといったところでしょうか。
## 爆弾搭載量
500lb爆弾が40発乗るようです。炸薬量は1発あたりTNT換算162.8kgとのことです。
1TNT換算グラムは1_000calなので、
```
162.8kg/発 * 40発 * 1_000cal/g = 6_512kg * 1_000_000cal/kg = 6_512_000_000cal
```
よって6Gcalぐらいらしいです。ほぼ一食分ですね。ちょうどいいです。

ちなみに計算してみて気付きましたが`9_071_858g≒9t`ですね。つまり私は同じ数値を物質として見るかTNTとして見るかで計算していたようです。
## 追加情報
現時点での下書きをチャットに投下したところ、追加情報を得られました。

C君によると「積載量=爆弾積載量」のつもりだったらしいです。まあGcalとか面白いし残すだけ残しておきます。

他にも、「あと震電ちゃんには爆弾だけじゃなくて載せてある燃料と機体材質と防御銃座とその弾薬と搭乗員も栄養になる」「一食2〜3機が普通」とのことです。

一通り計算し直すしかないですね。
## 新適正カロリー
今更ですが一食で燃料は全回復しそうですよね。つまり2～3機で6.7Gcalを補給していると考えてみます。
```
6_737_094_000cal / 2 = 3_368_547_000cal
```
になります。ちょうど2～3で割っているので1機あたり3.4Gcalを得ているという認識にすればよさそうです。
## 再計算
一旦各部を検討します

- 爆弾→爆発エネルギー換算
- 燃料→震電の燃料と同じように換算
- 機体→燃焼させた場合のエネルギー
- 防御銃座→機体に含まれる
- 弾薬→爆発と金属を燃焼させた場合のエネルギー
- 搭乗員→調べたら81_500cal/人でB-29は7人乗りなので570_500cal

爆弾は求まっていて燃料は可変なので後で検討するとして、機体をまず計算してみます。

機体の重さは34_660kgで、航空機には超ジュラルミンという合金がよく使われているらしいのでB-29もこれ製という仮定にします。
超々ジュラルミンを燃焼させた際には気合で計算したところ1gあたり23_433J発生するようです。
…という計算を既にしたあとに超ジュラルミンを使っていることを知ったので超超ジュラルミンの値で許してください。
```
34_660kg * 23_433J/g = 34_660_000g * 23_433J/g = 812_187_780_000J = 194_117_538_241cal
```
よって機体からは194Gcalが得られるようです。この時点で栄養過多ですね。

あとは弾薬を求めておきます。疲れてきたのでさっさとやっておきましょう。弾薬積載量は96_000発とのことです。
弾頭は中間ぐらいの700gr、45gと仮定しておきます。薬莢も合わせて100gぐらいということにしておきましょう。
薬莢は真鍮製で燃焼熱は3_415J/gです。火薬が15gぐらいあるらしいです。TNTと仮定して15_000calですね。
```
3_415J/g * 100g = 3_415_000J = 816_204cal
816_204cal + 15_000cal = 831_204cal
831_204cal * 96_000 = 79_795_584_000cal
```
弾薬は79.7Gcalです。悪くはないでしょう。。

合計タイムです。ちなみに燃料は後述します。
```
79_795_584_000cal + 194_117_538_241cal + 896_500cal = 273_914_018_741cal
```
273Gcalですね。本来は3.4Gcalなのでエネルギー効率が80分の1とかになってます。
B-29の燃料は24_885Lなので大体追加タンクありの震電の20倍です。戦闘とかして手に入れたものだと半分ぐらい入ってそうですよね。
ということで12_000L分の燃料は100Gcalぐらいなので373Gcalになります。エネルギー効率は110分の1だったらしいです。

健康食品の定義は分かりませんが、エネルギー効率がここまで悪い食品が健康に良いとは思えない気がします。
## まとめ
B-29は健康食品じゃない
